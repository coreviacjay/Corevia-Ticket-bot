# **Corevia Ticket Bot**

A fast, modular, production‑ready ticket system built for Discord servers.  
Designed with Corevia’s signature clean structure, global scalability, and professional workflow automation.

---

## ⚙️ **Environment Setup**

Create a `.env` file in the project root and add the following:

```
DISCORD_TOKEN=your_bot_token
CLIENT_ID=your_client_id
GUILD_ID=your_guild_id
STAFF_ROLE_ID=your_staff_role_id
LOG_CHANNEL_ID=your_log_channel_id
```
